# Third-Party Acknowledgments

Windowsill Essay Studio combines its own editorial workflow with optional specialized tools. This repository does not copy their full manuals, source code, templates, character designs, artwork or credentials.

The following projects informed or can support individual stages:

- **khazix-writer / Khazix skills** — narrative entry, rhythm and progression. Upstream: https://github.com/KKKKhazix/khazix-skills . This workflow does not impersonate Khazix or inherit his personal experiences.
- **gzh-design-skill** — WeChat inline HTML and theme components. Upstream: https://github.com/isjiamu/gzh-design-skill . Read the installed skill before using its components.
- **baoyu-skills** — illustration planning, covers, diagrams and infographics. Upstream: https://github.com/JimLiu/baoyu-skills . No upstream implementation or image assets are bundled here.
- **ian-xiaohei-illustrations** — visual metaphor and illustration-planning reference. This workflow uses original visual characters rather than reproducing the Xiaohei character.
- **guizang-social-card-skill** — editorial card and cover-layout reference; optional HTML rendering capability.
- **humanizer-zh** — optional Chinese prose editing while preserving information, author voice and uncertainty.
- **md-zhihu-reflection-typesetting-skill** — optional text-preserving native Zhihu formatting.
- **wechat-draft-push**, **zhihu-publisher**, **zhihu-mediacloud-uploader** — optional authorized delivery integrations; availability and authentication depend on the user's environment.
- **Runtime-native imagegen** — optional raster generation; not implemented or distributed by this repository.

Names without an upstream URL are integration identifiers, not a claim that a particular public installer or repository has been verified. Obtain each dependency from its own trusted source and check its license before redistributing it. The MIT license of this repository does not relicense any dependency.
