# 推送与核验

仅在当次用户要求或明确续接的未完成推送任务中使用。创建、安装和测试本Skill不授权平台上传。

## 授权与状态

本工作流默认将“公众号推送”解释为**上传后台草稿**；可由作者明确调整该约定，不自动解释为公开或群发。明确要求公开时核对目标文章及账号，按实际能力执行；不能把草稿报成公开。知乎按当次草稿／发布／回答／文章范围执行，未明确公开时采用草稿并说明。小红书仍仅手动交付。

写作、排版、上传正文图、上传草稿、公开发布和群发是不同状态。当前文章内部可记各平台 `not_requested / local_ready / upload_pending / draft_verified / published_verified / blocked`，附远端ID或链接、内容版本散列、图数、核验时间与阻塞原因；群发单列，只在证实后记结果。不建立虚假统一成功状态。

## 公众号

读可用 `wechat-draft-push`。若作者已有成功脚本与回执，可以作为实现参考，但不能直接运行旧文脚本，把新任务写进旧草稿。为当前文章创建任务副本并核对路径，不继承旧标题、摘要与图片数量；署名传空，基础工具的默认作者不是用户署名。

按当前要求校验标题、摘要、封面与正文；旧工具字节上限仅是本地兼容限制，不当成平台永恒规则。正文图先变成平台可访问资源，替换本地路径后上传。凭据从受保护的现有环境／配置最小化读取，不硬编码到Skill、文章、日志与分发包。不整份打印含密钥交接文件，不回显token及带token请求URL。

保存当前文章和远端草稿ID对应。已有成功ID先回读确认目标，再在授权内更新，不反复新建；已上传图可按散列复用。超时可能已成功，先查询核对再重试；不能判断则报不确定，避免重复。更新草稿不隐含修改已公开内容。

错误只报脱敏错误码及相关原因：
- `40164`：提取接口实际报出的当前出口IP，请用户加公众号白名单；不硬编码历史IP，不擅改安全配置。用户说已添加后再试一次并核验。
- 登录、凭据、权限问题：停止变更，指出缺少条件，保留本地交付。
- 其他错误按当前Skill说明诊断。只在原因修复且重复风险可控时重试，不因没有新证据无限请求或重复点击。

创建／更新后用读取接口核验标题、空署名、全文与顺序、正文图片和封面。比较平台规范化后的文本与资产，不因URL转义误判，也不忽略真缺图。保存脱敏回执，报告“已进入公众号草稿箱，未公开”，不编草稿公开URL。

## 知乎

查当前连接与授权；一次“已登录”不保证永久可用，历史插件故障也不代表今天仍故障。

- 有官方授权及工具：读 `zhihu-publisher`，按其当前版本检查、鉴权、校验、预览及发布流程执行；需要媒体再读 `zhihu-mediacloud-uploader`。不自动安装服务、更新Skill或索要明文密钥贴聊天。
- 使用浏览器：读当前可用控制Skill，确认正确账号和页面，仅走受支持权限与工具。插件故障按文档诊断，不用私有接口、窃取cookie或未经授权CDP绕开。
- 无可用路线：明确未上传，交保真Markdown／可复制文本、独立图片及图位说明，列具体缺失条件。

推送前确认问题回答／文章、账号、全文、图片及声明范围。保存后重载或重开，检查文字顺序、格式、图片及持久化。远端ID与状态确认后才报成功；网页已填不等于云端草稿。

## 报告

简短逐平台说明实际状态，附可用本地文件或已核实链接。一平台失败不抹掉另一平台成功，也不把成功平台的证据移作其他平台证明。内部留必要回执，不向用户倾倒请求日志。
