# 直接使用窗台作者的资源

## 这不是空白风格生成器
本Skill内置作者自己的思想底座、声线、语境案例及书籍综合。收到主题后先用这些资源，不默认要求使用者建立自己的风格、不把作者观点降格成可忽略的泛泛示例。当前作者的明确新反馈优先。

默认读 `resources/author/worldview.md` 与 `resources/author/voice.md`，按题目读取对应的语境和书籍资源。一次不需要加载所有文章或全部书库。

检索用于定位，不把结果数量当代表性。按 `quality-gates.md` 区分样本、个例、机制与建议。用户提交来批评的协作稿是回归样本，不自动加入作者认可的观点、声线或真实经历库；查重表只帮助定位，不证明已读完旧稿或理解了其中心。

## 检索

从Skill根运行：
```bash
python scripts/search_resources.py "兴趣 职业" --limit 5
python scripts/search_resources.py "退阶练习" --scope bundled --limit 4
```

默认 `auto`：若本机存在 `private/sources.json`，同时检索已登记原材料；否则使用随包资源。它不会扫描整盘、上传任何内容或调用平台。输出包含资源类别、文件、行号及文本区域；找到相关命中后，读完整节及前后条件，不只拿摘要写作。

要核对原话、说话人或历史事实时，本机原始材料优先；未连接本机时，用随包语境卡的完整重述发展论证，不冒充已读过私聊全文。没有私人配置也能写稿，不向新使用者索要一套新的作者资料。

## 区分三个实际层次
- `resources/author`：作者判断和风格，默认内容底座。
- `resources/contexts` 与 `resources/reading`：已整理进包的内容，可直接使用；原书直接引文另核。
- `private/sources.json`：只在作者本机存在的原始资源连接，帮助继续回读与查证，不随GitHub发布。

这不是“只写了路径就说知识已装入”。公开包真实包含资源正文；本机连接提供的是更完整的原始上下文。既有文章覆盖表供查重，协作稿不自动成为声线范文。

## 本机连接格式
配置由作者提供或在已授权资料路径下生成，不读取凭据：
```json
{"sources":[{"id":"chat-main","kind":"original_chat","path":"YOUR_EXISTING_CHAT.md"},{"id":"books","kind":"book_notes","path":"YOUR_EXISTING_NOTES_DIRECTORY","recursive":true}]}
```
占位路径只是格式说明，不是可执行默认。目录只枚举Markdown与TXT，文件只读；路径不存在在检索结果的警告中报告。原文可能含隐私，检索输出只供本地内部理解，不混进公开稿或发布日志。

## 作者视角与身份
以窗台作者的判断方式写稿，不是让调用者冒充其真实人生。署名仍留空。真实不等于应当写入：默认只转化思想，不调用聊天身份、履历和原例；具体边界见 source-context.md 的“思想与身份分离”。不得根据观点卡补造运动成绩、升学、创业与教学成功，更不能将第三方的事变成作者的事。

## 开源边界
公开包收录作者授权的匿名思想整理和短篇原创书籍综合，不收录完整私聊、第三方身份、书籍原文、账号与本机路径。外部Skill只是按需技术能力，不替代这里的作者资源。
