# 写作与编辑

## 选题与中心判断

写清读者困境、本文判断与理由、最强反对意见、答案改变的条件。查近期稿件的中心问题，不只比较标题。旧框架可能有不适合当前账号的受众定位，不能按编号机械续写。

先定主读者与真正需要解决的问题。家长问金额与保障，不能被改成只谈学生如何自律；没有统一数额也要给可核算的办法，不用“问题不在那个数”取消预算缺口。写作时执行[证据与一致性检查](quality-gates.md)，对没余量、没条件的人从前面就交代适用性与最低可行路径。

优先找熟悉事物中被忽略的目标、成本承担者、隐含标准或因果关系。小众靠解释成立，不靠语气离谱。价值取舍可以没有统一答案，事实仍需验证；不为评论把事实伪装成双方各有理，不用侮辱、群体定性和稻草人制造对立。

用钱、工作、安全、尊严、关系和选择找到生活入口，再说明常见解释少看了什么。热点、报道和社会争议按[知乎长文方法](zhihu-longform.md)补充事实卡与时点核查；生活关联、热度和灰度是选题线索，不是必须同时满足的资格。没有争议也可把一个有用的问题写透。

## 事件入口与推进

开头先有一件事情或具体选择，读者知道谁在为什么犹豫。真实故事有依据；说明性设想明确以“假设／想象”等标识，不能写成“前几天我遇到”。没有经历不强造故事。

一种可用但不固定的推进：具体矛盾 → 常见解释缺了什么 → 被忽略的条件／机制 → 换情境检验 → 最强反例与边界 → 可采用的判断或尝试 → 回扣开头。

分析单元可按“现象 → 机制 → 代价或替代方案”展开：谁遇到问题，什么条件造成它，谁承担成本，换一种做法需要什么。不是每节必须同样三段，也不能只列三个名词假装深入。重要事实先建立读者理解，再下相称的判断，不把通报重写一遍当分析。

术语与类比只能概括或解释，不增加证据力。对照数据要核单位、对象、时期和分母，不能把一个库存数字与另一个增长率并排当趋势。分类可交叉，方案前提与例外要清楚；同一规则在前后、正常与不足、必要与可选情形下不能相互冲突。

中段靠新条件、关系、反例和后果产生起伏，不靠“接下来最重要”催读。可保留疑问，在结尾完整回答，但沿途持续交付内容。简单答案先说，再解释为何难做到。新事情必须检验、补充或限定中心主张，讲清关联，不暗中换题水字数。

默认完整长文，约3000—5000字只是起稿参考，用户指定长度优先。不通过重复、无关故事和长引语凑数；缺论据则补材料或缩小主张，不用空话补深度。

## 自己的声音与卡兹克参考

保留进入问题快、认真聊天、明确判断、理解反方、节奏变化、前后呼应。

不沿用卡兹克身份、履历、科技账号定位、口头禅、脏话、每节动作配额、强制自谦、必然升华和标点禁令。当前已有材料时主动检索，不按专项默认反复要求投喂或确认提纲。

辨识度落在判断过程：为何承认现实，又为何不照搬常见答案；愿付什么代价；新信息出现时如何修正。融入书籍思想也要经过这层综合，不把读书摘要换成“我认为”就算文章。

句长与段长随语义变化。多分段照顾手机阅读，但不一律三行，不每句话独立成段。可用小标题和适量强调，不把参考Skill的“不用标题”硬带入平台。

融合旧知乎Skill的“克制的锋利”：有态度、会共情、肯查证，批评具体机制而非羞辱人群。让不同意者也能认出自己的理由；不为显得专业而认领专家身份，不预设官方、主流或自己必然正确，再倒推材料。

## 标题

承诺一个值得讨论的判断或行动方向，不只是描述现象，也不必硬塞“解药”字眼。正文能兑现，保留必要范围。不机械复用“别再X，Y才是答案”“你缺的不是X”等公式，不编数字、成绩和时长。

内部可比较少量角度后定一个，不强制每次审批。用户要求研究热门标题时查实际平台样本，记录日期与来源，不拿旧样本或生成标题冒充实时热榜。

## 语言编辑

先修误读，再修理由与转场，最后修句子。初稿后可用 `humanizer-zh` 修空话、重复和模板句，保持事实、否定、归因、条件、确定程度及计划／完成状态。

去掉时代开头、万能比喻、整齐排比、密集金句、每节重复总结和助手式寒暄。正常连接词、引号、破折号、有用的比喻不按黑名单删；好段落可保留。不用故意错字、乱逻辑或虚构情绪“去AI味”，不承诺检测结果。

具体细节必须有来源，不拿演示金额、虚构现场或猜测心理替代形容词；自然概括可以醒目，不设金句配额。首屏呈现处境、问题及阅读价值，沿途解开疑问，不机械延迟结论。

## 最强反方与结尾

不是只安排一个容易击倒的反对者：讲清反方保护什么、担心什么、何时它的选择更合理，再说明自己的取舍。事实错误不包装成另一种价值观，多方问题不硬切两派。先完成正文结论，再可选留一两个来自真实代价或条件的问题，让读者用经历补充；不强制煽动争吵，不用空泛的“你怎么看”替代收束。

默认给选定标题与完整正文，内部理解卡、事实卡、过程分析另存，不混入可复制稿。纯写稿不等于平台推送，成品也不等于审核或流量保证。

陌生读者不共享检索历史。首次引入人物、表格和研究先说明必要情境及来源，不从一个采访扩展出“一代人”，不替读者安排具体过去。结尾应检验前文主判断，不能新增缺证据的金额误差、心理规律或“必须有所牺牲”的普遍标准。

## 定稿检查与复盘

- 读者能复述中心主张，而不只记住漂亮话吗？
- 例子怎样支持结论，中间推理是否缺失？反方得到认真回应了吗？
- 哪些情境另一选择合理？每节是否增加理解？
- 标题、开头和结尾是否回答同一问题？建议是否符合揭示的约束？
- 有没有虚构经历、断章取义、夸大因果或把探索写成成功？
- 最终正文、来源记录、规则和结尾是否互相一致？每条自称完成的核验是否确实执行，还是只填了表？

反馈分层：理解错回原对话；论证薄补理由；标题弱重提判断；阅读困难修视觉；上传失败修流程。高赞笔手关于长文、争议、完读率及分发的说法只作经验假设。记录真实数据、分母与观察窗口，不许诺增长。
